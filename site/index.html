Reclaim City looks around your Mac or PC, tells you in plain English what it finds, and never changes anything unless you say so. Use it yourself, or hand a rescue stick to the person you're helping.

How it works

1

Open it up

Launch Reclaim City. It doesn't need an account, a subscription, or an internet connection to get started.

2

It looks around

It checks things like storage space, background apps, and common security settings — quietly, and without changing anything.

3

You decide

You'll see a plain-English summary. If something needs fixing, Reclaim City explains it and waits for your go-ahead.

The Rescue Stick

A USB drive with Reclaim City ready to run. No install, no internet, no Python. Plug it in, open the drive, and go.

  • Works on Mac and Windows — both binaries on every stick
  • Includes all 287 checks, 7 guided walkthroughs, and the quick-reference card
  • Hand it to someone and they can use it on their own
  • Nothing is uploaded — the tool works entirely offline

Perfect for the person in your life who is everyone's tech support, or for anyone who helps others with device security — counselors, IT volunteers, librarians, community organizations.

Not available yet. There’s no waiting list to join. Estimated price: $29–$39.

Good to know

  • Works on Macs (Apple Silicon and Intel) and on Windows 10 and 11. Linux users can run the command-line version from GitHub, with its own Linux checkup guide.
  • The installer is currently unsigned, so macOS and Windows will show a security prompt the first time — see the walkthrough above.
  • Nothing is uploaded anywhere. Reclaim City looks at your computer, not the other way around.
  • The source code is on GitHub — every check is a plain Python file you can read before you run it.
